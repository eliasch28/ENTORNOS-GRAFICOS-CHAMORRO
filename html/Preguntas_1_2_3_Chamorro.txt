-Ejercicio 1-
1. HTML fue creado en el año 1990 por Tim Berners-Lee y fue popularizado
por el navegador Mosaic (1993). Entre sus varias versiones se pueden mencionar a 
HTML 2.0, HTML 3.2, HTML 4.01, y su ultima versión, HTML 5.0.

2. El W3C recomienda que los agentes de usuario y los autores produzcan documentos HTML 4.01 en vez de documentos HTML 4.0. 
El W3C recomienda que los autores produzcan documentos HTML 4.0 en vez de documentos HTML 3.2.  Por razones de compatibilidad con 
versiones anteriores, el W3C también recomienda que las herramientas que interpreten HTML 4.0 sigan dando soporte a HTML 3.2 y a HTML 2.0

3. Un elemento o atributo desaprobado es aquel que ha quedado anticuado por la presencia de estructuras nuevas. Por otro 
lado, un elemento o atributo obsoleto es aquél para el cual no hay garantía de soporte por parte de un agente de usuario.

4. El DTD (definición del tipo de documento) define la sintaxis de las estructuras de formato, y se coloca en la primera línea del 
archivo antes de la etiqueta <html>. En HTML 4.01 existían dos tipos principalesde DTD: Transitional (transitoria) y Strict (estricta).

5. Llamamos metadatos a toda la información sobre un documento más que solo su contenido propio. Se especifican mediante la etiqueta <meta>, 
la cual se coloca siempre dentro de la sección <head> del documento. Por ejemplo: Por ejemplo, "<META name="Author" content="Dave Raggett">".

-Ejercicio 2-
2.a) Es un comentario. Se puede colocar en cualquier sección del código. No produce efecto visual en el navegador y sirve para documentar cosas en el código.
2.b) Elemento de caja/bloque. Se coloca solamente en el <body>. Sirve para agrupar contenidos. El atributo id identifica de forma única al elemento pero no es obligatorio.
2.c) Elemento de imagen. Se coloca solo en el <body>. El atributo src es obligatorio pues indica la ruta de la imagen, y alt es obligatorio por buenas practicas ya que 
muestra un texto si la imagen no carga. Los atributos id, name, width, height, longdesc no son obligatorios pues cambian en general elementos visuales y agregan utilidad
para la hora de codificar (el id solamente).
2.d) Metadatos. Se colocan exclusivamente en la parte del <head>. Definen palabras clave para los motores de búsqueda. Ningún atributo resulta obligatorio, todo depende de
la utilidad o fin que tenga el uso de <meta>.
2.e) Hiperenlace. Se coloca en el <body>. El atributo href es totalmente obligatorio pues sirve para indicar el destino del enlace, mientras que sus otros atributos no
resultan obligatorios de colocar (pero constituyen buenas practicas como por ejemplo el type).
2.f) Tablas. Se coloca unicamente en el <body>. Define filas <tr> y celdas de datos <td> o encabezados <th>. Todas estas sub-etiquetas pueden contener atributos que
afecten al aspecto pero ninguno indispensable.
